# VPN не работает — диагностика

## Быстрые проверки

### 1. XRay на сервере
```bash
ssh root@194.48.142.252 "systemctl status xray"
```
Должен быть `active (running)`.

### 2. Порты
```bash
ssh root@194.48.142.252 "ss -tlnp | grep -E '443|80'"
```
Должны слушать XRay.

### 3. Доступность снаружи
```bash
nc -zv 194.48.142.252 443
```
Если `Connection refused` — возможна блокировка на уровне хостинга (security group, файрвол провайдера).

### 4. Конфиг пользователя
- Ссылка должна содержать **194.48.142.252** (не 185.245.35.92, не 89.40.233.3)
- Нажать в боте «Подключиться» и получить свежую ссылку
- Обновить ссылку в приложении (v2rayTun, Hiddify и т.п.)

### 5. Подписка
- Если подписка истекла — enforcer делает suspend, трафик не идёт
- Продлить подписку в боте

### 6. Роутинг
- Вернули **оригинальный роутинг** (без правила с `proxy`)
- RU/яндекс → direct, остальное → VPN по умолчанию
- Если импортировали новый роутинг с Gemini — заново получить в боте и применить

## Известные причины

| Симптом | Что сделать |
|--------|-------------|
| «Зависло на Подключение» | Обновить ссылку в боте, проверить IP 194.48.142.252 |
| «Нет трафика» | Проверить подписку, сверить ссылку и роутинг |
| «Connection refused» | Проверить firewall/security group на хостинге |
| Gemini «не поддерживается в стране» | Трафик идёт через 194.48.142.252; если сервер в заблокированном регионе — на сервере направить трафик Gemini через прокси в США/ЕС. См. [GEMINI_ROUTING.md](GEMINI_ROUTING.md) |
| lovable.dev не открывается | Сервер: добавить lovable.dev в direct, выполнить push |

### 7. sales.trimagent.pro недоступен по VPN

**Причина:** при включённом VPN трафик к сайту идёт через сервер 194.48.142.252; хостинг или WAF (Cloudflare и т.п.) может блокировать IP датацентров/VPN.

**Что сделано:** в клиентском роутинге домены `trimagent.pro` и `sales.trimagent.pro` добавлены в правило **direct** — трафик к ним идёт в обход туннеля (как у RU-доменов). Сайт открывается с вашего обычного IP.

**Пользователю:** заново получить роутинг в боте («Подключиться» → скопировать ссылку роутинга и применить в v2rayTun/приложении).

### 8. lovable.dev и Gemini — правки на сервере

Эти сайты должны быть в правиле **direct** в `config_server.json` на 194.48.142.252:

- `lovable.dev`, `www.lovable.dev`
- `gemini.google.com`, `generativelanguage.googleapis.com`, `ai.google.dev`

После правки конфига:
```bash
ssh root@194.48.142.252 "cd /root/easy-xray && echo 'S' | ./ex.sh push"
```
